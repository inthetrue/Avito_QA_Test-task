# Баги по скриншотам

Задание 1 Avito QA, осень 2026. Эталон значений - форма редактирования. Анализ выполнен по скриншотам.

P0 - критический, P1 - высокий, P2 - средний, P3 - низкий приоритет.

## 01. Неверная цена - P1

Где: Карточка товара, цена.  
Фактически: 52 000 ₽.  
Ожидается: 25 000 ₽.

# Баги API

Окружение: учебный стенд `https://qa-internship.avito.com`, HTTPS, Python 3.14, pytest 9.2.0, requests 2.34.2. Проверки выполнены на собственных динамически созданных пользователях и объявлениях. Оба дефекта повторно проверены на новом объявлении. Токены и пароли в отчёт не включены.

## API-01. Статистика v1 возвращает данные удалённого объявления

- Приоритет: P2. Серьёзность: Major (ошибка согласованности данных).
- Запрос: `GET /api/1/statistic/{id}`.
- Предусловия: зарегистрировать пользователя, авторизоваться и создать объявление с его sellerID и счётчиками `likes = 21`, `viewCount = 11`, `contacts = 43`; сохранить UUID из ответа создания.
- Шаги: удалить объявление через `DELETE /api/2/item/{id}` с собственным токеном; проверить через `GET /api/1/item/{id}`, что объявление отсутствует; запросить статистику v1 по тому же UUID.
- Фактически: DELETE возвращает 200, чтение объявления - 404, но статистика v1 - 200 и прежние данные: `[{"contacts":43,"likes":21,"viewCount":11}]`.
- Ожидается: статистика удалённого объявления не выдаётся как статистика существующего; ожидаемый код отсутствующего ресурса в тесте - 404.
- Автотест: `test_deleted_item_statistics[1]`, сценарий STAT1-02.

## API-02. Статистика v2 возвращает данные удалённого объявления

- Приоритет: P2. Серьёзность: Major (ошибка согласованности данных).
- Запрос: `GET /api/2/statistic/{id}`.
- Предусловия: зарегистрировать пользователя, авторизоваться и создать объявление с его sellerID и счётчиками `likes = 21`, `viewCount = 11`, `contacts = 43`; сохранить UUID из ответа создания.
- Шаги: удалить объявление через `DELETE /api/2/item/{id}` с собственным токеном; убедиться, что `GET /api/1/item/{id}` возвращает 404; запросить статистику v2 по тому же UUID.
- Фактически: статистика v2 возвращает 200 и прежние данные: `[{"contacts":43,"likes":21,"viewCount":11}]`, хотя объявление уже удалено.
- Ожидается: статистика удалённого объявления не выдаётся как статистика существующего; ожидаемый код отсутствующего ресурса в тесте - 404.
- Автотест: `test_deleted_item_statistics[2]`, сценарий STAT2-02.

Версии вынесены отдельно, поскольку это разные ручки и отдельные проверки. Общая причина без доступа к реализации неизвестна. Для очистки тесты удаляют объявления; отдельного запроса удаления оставшейся статистики в коллекции нет.
